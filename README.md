# Вайб&Код — проектная работа по информатике

**Тема:** «Использование ИИ и вайбкодинга в повседневной жизни и школьных задачах»

Одностраничный сайт-презентация проектной работы. Минималистичный дизайн, тёмная/светлая тема, адаптивность под мобильные устройства. Без сборщиков и зависимостей — чистые HTML/CSS/JS.

## Структура работы (секции сайта)
1. **Введение** — актуальность, проблема, гипотеза, цель, задачи, методы
2. **Раздел I: ИИ вокруг нас** — что такое ИИ и LLM, история, бытовые сценарии, галлюцинации
3. **Раздел II: Вайбкодинг** — термин А. Карпатого, сравнение инструментов (Cursor, Bolt, Lovable…), цикл разработки
4. **Раздел III: ИИ в школьных задачах** — результаты анкетирования (интерактивная диаграмма), сценарии по предметам
5. **Раздел IV: Этика и безопасность** — «можно/нельзя», 5 правил промпта, интерактивный тренажёр сборки промпта
6. **Практическая часть** — эксперимент «сайт за вечер» + живой JS-виджет
7. **Заключение** — выводы, рекомендации, взгляд вперёд
8. **Источники**

## Запуск
Просто откройте `index.html` в браузере, либо:
```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Файлы
- `index.html` — разметка и весь текст работы
- `style.css` — дизайн (CSS-переменные, темы, анимации)
- `script.js` — интерактив (тема, меню, счётчики, тренажёр промптов)

> 💡 Перед защитой: замените проценты в диаграмме анкетирования на реальные данные вашего опроса и впишите номер класса в разделе III.
